### CC BY-SA 4.0 notice for the shared phrase lists

A word-for-word comparison of this skill against the page, run on 2026-11-12, found no shared headings and no shared prose sentences. It found six ordered lists of short phrases that appear in the same order on both. They cover about 4% of this skill's words and sit in these places in SKILL.md:

- Channel 1 (ZERO-DRIFT BOUNDARY): a list of vague attributions.
- Channel 10 (VOCABULARY PROFILE FLATTENING): three lists, covering importance-inflating wording, stock phrases such as "key turning point", and promotional wording.
- Channel 13 (RESIDUAL-ARTIFACT SWEEP): two lists, covering chatbot phrases and knowledge-cutoff or source-availability disclaimers.

## Aboudjem/humanizer-skill

- Repository: https://github.com/Aboudjem/humanizer-skill
- Author: Adam Boudjemaa
- License: MIT (notice below)
- Version reviewed: repository commit a58df06 (2026-09-06), accessed 2026-11-12

This published humanizer skill lists AI-tool markup leaks across five chatbot providers, along with the tracking parameters those tools add to URLs. It also applies a tiered vocabulary rule that treats lower-tier words as evidence only in clusters, and it protects quoted, technical and human-written text. Each of these parallels this skill.
